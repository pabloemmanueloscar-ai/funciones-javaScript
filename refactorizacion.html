Anotaciones sobre la refactorización

  1. ¿Qué partes del código original se repetían?

    Para cada producto se calculaban por separado el subtotal, el descuento y el total, y luego se mostraban los datos. Esas operaciones se repetían para el teclado y el mouse. Ahora los cálculos se realizan mediante funciones reutilizables.

  2. ¿Qué ventajas ofrece utilizar funciones?

    Las funciones evitan duplicar instrucciones, organizan el programa en tareas pequeñas y facilitan leer, probar, corregir y ampliar el código. Por ejemplo, se puede agregar otro producto sin volver a escribir la lógica de los cálculos.

  3. ¿Qué diferencia existe entre mostrar un resultado con console.log() y devolverlo mediante return?

    console.log() muestra información en la consola para que una persona pueda verla. return entrega un valor al código que llamó a la función, de modo que pueda guardarlo, reutilizarlo o usarlo en otro cálculo.

  4. ¿Por qué es importante que una refactorización conserve el comportamiento original?

    Porque el objetivo es mejorar la organización interna sin cambiar los resultados que ya espera quien usa el programa. En este ejercicio, los totales originales del teclado y el mouse se mantienen; los auriculares agregan un resultado nuevo por el desafío adicional.
